# Rock Paper Scissors Game 🎮

## About the Project
This is a simple Rock Paper Scissors game developed using Python. In this game, the user plays against the computer.

## Features
- User vs Computer gameplay
- Random computer choices
- Score tracking
- Win, Lose and Draw conditions
- First player to reach 5 points wins the game

## Technologies Used
- Python
- Random Module

## How to Run
1. Download or clone this repository.
2. Open the project in VS Code.
3. Run the following command in the terminal:

```bash
python stone_paper.py
```

## Game Rules
- Stone beats Scissors.
- Scissors beats Paper.
- Paper beats Stone.
